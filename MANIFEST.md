# Bundle MANIFEST

Snapshot of all files produced during the nginx-sec-lab debugging and
documentation session. Extract this zip over your repo root to apply
every change at once, or pick individual files.

## Layout

Files are at their canonical repo paths. Extracting:

```bash
cd ~/nginx-sec-lab
unzip -o ~/Downloads/nginx-sec-lab-bundle.zip
chmod +x scripts/*.sh
```

`unzip -o` overwrites without prompting. Skip the flag if you want
interactive prompts.

## What this bundle does NOT include

- `lab.env` / `lab.secrets` — these are local config and must stay
  out of git. Use `lab.env.example` as the template.
- `root_ca.crt` / `root_ca.key` — generated by `task ca:init` on first
  `task up`. Treat the key as a secret.
- `helmfile.yaml`, `registries.yaml`, `lab.env.example`,
  `lab.secrets.example` — unchanged from the upstream repo.
- `scripts/create-cluster.sh`, `scripts/install-ubuntu.sh`,
  `scripts/check-prereqs.sh`, `scripts/pre-deploy.sh`,
  `scripts/import-images.sh`, `scripts/setup-registry.sh`,
  `scripts/install-cni.sh`, `scripts/health-check.sh`,
  `scripts/test-endpoints.sh`, `scripts/apps-waf.sh`,
  `scripts/install-cis.sh`, `scripts/bigip-configure.sh` — unchanged
  from upstream.
- `base/juiceshop/`, `base/dvga/`, `base/vampi/`,
  `base/crapi/deployment-*.yaml`, `base/crapi/ingress.yaml`,
  `base/crapi/certificate.yaml`, `base/crapi/kustomization.yaml`,
  and all of `overlays/`, `policies/`, `cni/` — unchanged.

## Applying piecemeal

If you'd rather not overwrite everything, the files that produced the
most impact in this session were:

1. `Taskfile.yaml` (apps:up readiness wait, logs selectors)
2. `manifests/nginx-podmonitor.yaml` (observability that actually works)
3. `base/crapi/services.yaml` (workshop port fix)
4. `jobs/gotestwaf-job.yaml` (scan args fix)
5. `README.md` + `docs/` (documentation)

Apply those four files + docs/ and you have ~90% of the value.

## Provenance

Every file in this bundle was validated end-to-end during the session
on a live lab. The fixes have been seen working — `task reset →
task health → task test → task scan` all complete cleanly.
